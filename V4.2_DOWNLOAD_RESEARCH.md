# V4.2 WKDownload Mimarisi ve İndirme Motoru Araştırması
**Repository:** `NativeWKWebViewTest`  
**Referans Baseline:** `a9d761b` (V4.1 Güvenlik İzolasyonu)  
**Hedef:** WebKit'in yerel `WKDownload` altyapısı ile iOS sandbox içinde güvenli, tam kontrollü ve takip edilebilir bir indirme motoru geliştirmek.

---

## 1. WKDownload Yaşam Döngüsü ve Apple API Mimarisi

Apple, iOS 14.5 ve macOS 11.3 ile birlikte `WKWebView` içerisindeki dosya indirme operasyonlarını resmileştiren **`WKDownload`** API ailesini sunmuştur.

### API Akışı:
```text
Kullanıcı Linke Tıklar veya Sayfa Dosya Sunar
               │
               ▼
BrowserNavigationDelegate: decidePolicyFor navigationResponse
  ├── canShowMIMEType == false ?
  ├── Content-Disposition: attachment ?
  └── Dosya uzantısı / MIME türü kontrolü
               │
               ├─► [Standart HTML/CSS/JS] ──► decisionHandler(.allow)
               │
               └─► [İndirilebilir Dosya]   ──► decisionHandler(.download)
                                                   │
                                                   ▼
WKNavigationDelegate: navigationResponse:didBecome download: WKDownload
                                                   │
                                                   ▼
                                     BrowserDownloadManager (WKDownloadDelegate)
                                       ├── decideDestinationUsing:suggestedFilename:
                                       ├── Progress KVO Observation (\.fractionCompleted)
                                       ├── willPerformHTTPRedirection: (Yönlendirmeler)
                                       ├── downloadDidFinish: (Tamamlanma)
                                       └── download:didFailWithError: (Hata / İptal)
```

## 2. Navigasyon Yanıtından (Navigation Response) İndirmeye Geçiş

`WKNavigationDelegate` protokolündeki `decidePolicyFor navigationResponse`:
```swift
func webView(_ webView: WKWebView, decidePolicyFor navigationResponse: WKNavigationResponse, decisionHandler: @escaping (WKNavigationResponsePolicy) -> Void)
```
Bu aşamada sunucunun HTTP yanıt başlıkları (HTTP headers) gelmiş, ancak dosya gövdesi (body) henüz indirilmemiştir.

### İndirme Tetikleme Kriterleri:
1. **`navigationResponse.canShowMIMEType == false`:** WebKit ilgili MIME tipini (örneğin `application/zip`, `application/octet-stream`, `application/x-tar`, `.exe`) doğrudan görüntüleyemiyorsa.
2. **`Content-Disposition` Başlığı:** Sunucu `Content-Disposition: attachment; filename="rapor.pdf"` başlığı göndermişse.
3. **Belirlenmiş İndirme Uzantıları:** URL yolu açıkça `.zip`, `.tar.gz`, `.7z`, `.dmg`, `.pkg` gibi arşiv/ikili dosya uzantıları içeriyorsa.

Bu koşullardan biri sağlandığında `decisionHandler(.download)` döndürülür. Ardından WebKit:
```swift
func webView(_ webView: WKWebView, navigationResponse: WKNavigationResponse, didBecome download: WKDownload)
```
metodunu çağırarak indirme sürecini başlatan `WKDownload` nesnesini teslim eder.

## 3. iOS Sandbox Depolama ve Dizin Mimarisi

iOS sandbox kuralları uyarınca bir üçüncü taraf uygulamanın dosya yazabileceği standart dizinler:

| Dizin | Konum | Kullanım Amacı | Yedekleme (iCloud) |
| :--- | :--- | :--- | :--- |
| **`Documents/Downloads`** | `<App_Home>/Documents/Downloads/` | Kullanıcının ürettiği / indirdiği kalıcı dosyalar. | Evet (İstenirse kapatılabilir) |
| **`Library/Caches/Downloads`** | `<App_Home>/Library/Caches/Downloads/` | Geçici, silinebilir önbellek dosyaları. | Hayır |
| **`tmp/`** | `<App_Home>/tmp/` | Anlık geçici dosyalar (OS silebilir). | Hayır |

### V4.2 Kararı:
İndirilen dosyalar `<App_Home>/Documents/Downloads/` dizinine kaydedilecektir.  
`Info.plist` içinde `UIFileSharingEnabled = YES` ve `LSSupportsOpeningDocumentsInPlace = YES` yapılandırmasıyla bu dizin, kullanıcının iPad üzerindeki **Dosyalar (Files)** uygulamasından doğrudan görüntülenebilir. İleride Obsidian entegrasyonunda dosyalar doğrudan Obsidian Vault dizinine yönlendirilecektir.

## 4. Dosya Adı Güvenliği ve Path Traversal Koruması

Sunucudan gelen `suggestedFilename` veya `Content-Disposition` parametreleri doğrudan dosya yolu olarak **kullanılamaz**.

### Alınan Güvenlik Önlemleri:
1. **Path Traversal Engelleme:**
   * `../`, `..\\`, `/`, `\` gibi dizin değiştirme dizilimleri regex ve string temizleme ile tamamen kaldırılır.
   * Dosya adı başındaki gizli dosya noktaları (`.`) temizlenir.
2. **Geçersiz ve Tehlikeli Karakterler:**
   * iOS dosya sisteminde yasaklı veya kontrol karakterleri (`:`, null byte `\0`, `*`, `?`, `"`, `<`, `>`, `|`) filtrelenir.
3. **Boş Ad Koruması:**
   * Temizleme sonrası ad boş kalırsa varsayılan olarak `download.bin` veya `download` adı atanır.
4. **Çakışma Koruması (Collision Avoidance):**
   * Eğer hedef dizinde aynı isimde dosya varsa üzerine yazılmaz (`file.pdf` -> `file (1).pdf` -> `file (2).pdf`).
5. **Dizin Sınırı Doğrulaması:**
   * Nihai hedef URL'nin `standardizedFileURL.path` değeri `downloadsDirectory.standardizedFileURL.path` ön ekine sahip olduğu kesinleştirilir.

## 5. İlerleme Takibi (Progress Reporting) ve İptal (Cancellation)

### İlerleme:
* `WKDownload`, `NSProgressReporting` protokolünü uygular ve `var progress: Progress { get }` özelliğine sahiptir.
* `progress.observe(\.fractionCompleted)` kullanılarak indirme oranı `0.0 ... 1.0` aralığında dinlenir ve `BrowserEvent.downloadProgressChanged` üzerinden arayüze aktarılır.

### İptal (Cancel):
* `WKDownload.cancel { resumeData in ... }` metodu ile indirme anında durdurulur.
* İptal edilen indirmenin yarım kalan hedef dosyası dosya sisteminden temizlenir ve state `cancelled` olarak işaretlenir.

---

## 6. Yönlendirmeler (HTTP Redirects) ve Durum Yönetimi

* İndirme bağlantısı 301/302 yönlendirmesi yaptığında `WKDownloadDelegate`:
  ```swift
  func download(_ download: WKDownload, willPerformHTTPRedirection response: HTTPURLResponse, newRequest request: URLRequest, decisionHandler: @escaping (WKDownload.RedirectPolicy) -> Void)
  ```
  metodunu çağırır.
* Bu yönlendirme `[DOWNLOAD] REDIRECT: HTTP ...` olarak loglanır ve `decisionHandler(.allow)` ile nihai hedefe izin verilir. Nihai URL indirme modelinde güncellenir.

---

## 7. WebKit'in Bilinen Sınırları (Known Limitations)

1. **JavaScript Blob URL İndirmeleri:** Bazı web siteleri (`blob:https://...`) dosyaları bellekte üretip `<a>` download linki ile tetikler. Bu tür blob indirmelerinde sunucu başlıkları yerine JavaScript tarafından oluşturulan veriler aktarılır.
2. **Arka Plan İndirmeleri (Background Downloads):** `WKDownload`, `NSURLSessionDownloadTask(backgroundConfiguration)` kadar derin iOS arka plan indirme yeteneğine sahip değildir; uygulama arka plana atıldığında WebKit süreci iOS tarafından askıya alınabilir.
